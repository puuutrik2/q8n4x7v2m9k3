# BLANCH Family Site

Сайт семьи BLANCH для GTA 5 RP с Discord-логином, формой заявки и отправкой заявок ботом в Discord.

## Запуск

1. Создать `.env` по примеру `.env.example`.
2. Запустить:

```powershell
npm start
```

3. Открыть:

```text
http://127.0.0.1:4183
```

## Важно

Файл `.env` не должен попадать в GitHub, там находятся токены Discord.
